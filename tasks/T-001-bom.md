# T-001: Collect the full BOM
**Status:** todo
**Depends on:** the user being home with the parts

## Goal
Know exactly which parts exist, so the pin map, power design and chassis can be planned.

## Done when
- [ ] `docs/bom.md` lists every part with its model, key specs and quantity
- [ ] Motors: count, voltage, encoders yes/no, dimensions and mounting holes
- [ ] Motor driver model (L298N, TB6612, L9110...)
- [ ] Bluetooth module model (HC-05 vs HC-06 decides whether it can be the remote master)
- [ ] Sensors: model names
- [ ] Power: battery type and voltage, regulators or buck converters
- [ ] Programmer: ST-LINK V2 clone (does it have an RST pin?), USB-UART adapter?
- [ ] Wheels: diameter and width. Omni/caster wheel: full height and mounting holes
- [ ] 3D printer model and filament

## Notes / log
Photos next to a ruler are fine for parts with unclear markings.
